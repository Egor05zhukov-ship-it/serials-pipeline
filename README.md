# serials-pipeline

Собирает вертикальную серию 1080×1920 из текста: озвучка по фразам, субтитры, рисованные кодом кадры (SVG), фоновый звук, mp4, обложка и подпись к посту.

## Сборка

```bash
./setup.sh                                                  # один раз: ffmpeg и зависимости
node build.js series/nochnaya-smena/ep01.js --tts yandex    # вся серия
node build.js series/nochnaya-smena/ep01.js --tts piper --still 0,12.5,40   # только отдельные кадры, быстро
node build.js series/nochnaya-smena/ep01.js --tts piper --still shots       # по три кадра на каждую сцену
```

Результат в `out/<сериал>-epNN/`: `video.mp4`, `cover.jpg`, `caption.txt`, `contact.jpg` (кадр каждые 3 секунды, для проверки глазами).

Нужны Node 20–22, ffmpeg и Chrome. Путь к Chrome берётся из `CHROME_PATH`, иначе ищется в стандартных местах macOS и Linux.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `TTS` | голос по умолчанию, если не указан `--tts`: `yandex`, `elevenlabs`, `piper`, `say` |
| `YANDEX_API_KEY`, `YANDEX_VOICE`, `YANDEX_SPEED`, `YANDEX_EMOTION` | Yandex SpeechKit |
| `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`, `ELEVENLABS_MODEL` | ElevenLabs |
| `PIPER_PYTHON`, `PIPER_MODEL`, `PIPER_SPEED`, `PIPER_PITCH` | локальный Piper, только для черновиков |
| `SAY_VOICE`, `SAY_RATE` | голос macOS, только для черновиков на Маке |
| `RENDER_WORKERS` | сколько вкладок Chrome рисуют кадры одновременно (по умолчанию 3) |
| `CHROME_PATH` | путь к Chrome |

Провайдеры `yandex` и `elevenlabs` написаны по документации, но с настоящим ключом ещё не запускались.

## Как устроена серия

Файл серии (`series/<сериал>/epNN.js`) экспортирует объект:

- `narration`: фразы по порядку. Одна фраза = один файл озвучки. `*слово*` красит слово в субтитрах, одиночный `|` ставит разрыв субтитра, `gap` задаёт паузу после фразы.
- `shots`: сцены. `from` это номер первой фразы сцены, `draw(p, t, c)` возвращает SVG кадра. Длина сцены получается из озвучки, руками её не задают.
- `sfx`: акценты из `audio/ambient.js` с привязкой к фразе.
- `cover`, `post`, `endCard`: обложка, подпись к посту, финальная плашка.

Рисуют из готовых деталей в `kit/index.js`: комната, лампа, стеллаж, стойка, коробка, записка, окно выдачи, герой, гостья в капюшоне, ладонь, бейдж, плашка с временем. Новую деталь добавляют туда же, чтобы она выглядела одинаково во всех сериях.

Новая серия: скопировать `ep01.js`, заменить текст и сцены, прогнать `--still shots`, посмотреть кадры, потом собрать целиком.

Полная сборка минутной серии на Маке с M4 занимает около 1 мин 45 с (кадры рисуются в три вкладки Chrome).

## Звук

Фон делается самим ffmpeg (`audio/ambient.js`), ничего не скачивается. Итог приводится к −14 LUFS. Конкретные шумы (стук, дверь, шаги) кодом получаются плохо: их нужно брать из настоящих записей со свободной лицензией.

## Шрифт

Montserrat, лицензия OFL (`fonts/OFL.txt`).
