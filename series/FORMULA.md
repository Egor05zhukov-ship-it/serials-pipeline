# Правила сценария серии

Рабочий документ для того, кто пишет серию (человек или ночной агент). Сначала прочитай `series/SCENARIST.md` (на Маке это же навык `serial-scenarist`): он отвечает за то, чтобы история цепляла. Затем `bible.md` своего сериала. Этот документ про размер, разметку и проверку.

## Размер и ритм
- 95–125 слов связными предложениями вместе с вопросом в конце; ролик 50–68 секунд (темп голоса 1,05). Как рассказывать: `series/SCENARIST.md`, раздел 0. Порядок серии: `series/SCENARIST.md`, разделы 1–4.
- От первого лица или на «ты», прошедшее время. Одна строка таблицы `N` = одно предложение = один файл озвучки. Знак `|` в `text` делит предложение на куски субтитра по три-пять слов; голосу он не мешает. Картинка внутри длинного предложения меняется по доле его длины (`c.since(i) / c.dur(i)`), как в образцах.
- Простые слова, без канцелярита и англицизмов. Слов с неочевидным ударением избегать: заменять.
- Смена плана каждые 2–5 секунд: на серию 16–22 сцены.

## Первые секунды
- Речь начинается с нулевой секунды, без заставки и приветствий.
- Первые три фразы: место, беда, первая странность. Серия должна быть понятна тому, кто не видел предыдущих.
- В сериях 2+ вторая-третья фраза говорит, что выбрали зрители («Вы выбрали ждать ночи» или «В прошлой серии решили ждать ночи», см. `series/SCENARIST.md`, раздел 4).

## Середина
- Четыре-пять странностей за серию, каждая вытекает из предыдущей фразы (`series/SCENARIST.md`, раздел 0). Чисел вслух не больше двух.
- Героев не представлять: без возраста, профессии и плашек с именем.
- Одна немая улика в кадре, о которой голос не говорит. Она должна сыграть через 1–3 серии.
- Счётчик сериала показывается плашкой и меняется от серии к серии.

## Конец
- Последняя фраза истории: одна улика до семи слов.
- За ней выбор зрителя: один вопрос с двумя действиями («Как бы ты поступил: открыл люк или затаился?») и просьба («Напиши в комментариях и перешли другу: пусть выберет тоже»). Это две строки таблицы `N`, под ними последний кадр `choiceCard` из `kit/v2.js` (варианты под буквами А и Б появляются, когда голос их называет).
- В объекте серии поле `choice: { a: 'Открыть люк', b: 'Ждать ночи' }` (одной строкой, в одинарных кавычках): по нему сборка считает голоса в комментариях.
- Финальная плашка: «Продолжение завтра», ниже «Серия N+1». В финале сезона выбора нет, плашка «Новый сериал завтра».

## Чего не делать
- Не копировать сюжеты, героев, реплики и рисовку чужих аккаунтов.
- Людей рисовать только набором `kit/people.js` (`human`, `shade`, `crowd`); `person` из `kit/v2.js` остался для старых сериалов.
- Без мата, расчленёнки и крови крупным планом: страшно то, чего не видно.
- Всё, что касается устройства места (двери, фильтры, свет, вода), должно быть правдоподобным. Сомневаешься в детали — не используй её.
- Никакой рекламы внутри сюжета.

## Разметка в файле серии
- `*слово*` красит ключевое слово субтитра (одно на фразу, не в каждой фразе).
- Реплики персонажей начинаются с тире.
- Числа пишутся словами, как их должен прочитать диктор.

## Звук и необязательные поля
```js
sfx: [
  { type: 'impact-low', phrase: 'open', vol: 0.5 },             // удар на первом слове; phrase = id фразы
  { type: 'door-creak', phrase: 'door', at: 0.2, vol: 0.7 },    // звук места; at = доля длины фразы, offset = секунды
  { type: 'wind-howl', phrase: 'night', loop: true, dur: 9, vol: 0.2 }, // фон под сценой: loop и dur
  { type: 'impact-low', phrase: 'last', offset: -0.1, vol: 0.8 },
],
slot: '20:37',          // необязательно: время выхода этой серии по Москве (10:00–22:59), опыт со временем
experiment: 'первая фраза со сроком вместо счёта; жду skipRate ниже 30 %', // что проверяет серия
choice: { a: 'Открыть люк', b: 'Ждать ночи' }, // выбор зрителя в конце серии
```
Записи: `box-slide`, `car-door`, `car-idle`, `car-pass`, `child-cough`, `door-creak`, `door-latch`, `heartbeat`, `impact-low`, `knock-door`, `knock-glass`, `lamp-buzz`, `match-strike`, `paper-rustle`, `radio-static`, `starter-fail`, `steps-snow`, `wind-howl`, `wind-storm`. Синтетический удар: `hit`. Не больше 6–8 звуков на серию, громче 0.9 не ставить.

## Подпись к посту (`post`)
- Первая строка: странность серии утверждением. Затем «„Название“, серия N.».
- Строка выбора: «А — открыть люк, Б — затаиться. Напиши в комментариях». Строка «Перешли тому, с кем оказался бы там».
- 4–5 хештегов по теме. Без ссылок.

## Проверка перед тем, как считать серию готовой
1. `node build.js <серия> --tts <голос> --still shots` и посмотреть кадры: текст не налезает, герои те же, субтитры читаются.
2. Полная сборка, затем посмотреть `contact.jpg`.
3. Длина 50–68 с, громкость около −14 LUFS, первое слово на 0,0 с, файл меньше 10 МБ.
